# rforkids

**rforkids** es un paquete educativo en R diseñado para enseñar conceptos básicos de estadística a niños mediante una interfaz gráfica simple en escritorio usando `tcltk`.

## 🚀 Instalación

Una vez subido a GitHub, puedes instalarlo con:

```r
install.packages("devtools")  # si no lo tienes aún
devtools::install_github("diegomezapy/rforkids")
```

## ▶️ Uso

Al cargar el paquete, la interfaz se lanza automáticamente:

```r
library(rforkids)
```

## 🧰 Funcionalidad

- Ingreso de 5 números
- Cálculo de máximo y mínimo
- Gráfico de barras
